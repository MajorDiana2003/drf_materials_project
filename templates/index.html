Панель навигации по API (ДЗ 30.1)

Используйте ссылки ниже для быстрого перехода к проверке эндпоинтов в браузере:

📚 Курсы (ViewSets)

  • GET /materials/courses/ — Список курсов и форма создания (POST)

📝 Уроки (Generics)

  • GET /materials/lessons/ — Список всех уроков
  • POST /materials/lessons/create/ — Форма создания урока
  • GET /materials/lessons/1/ — Просмотр урока с ID = 1
  • PUT /materials/lessons/update/1/ — Редактирование урока с ID = 1
  • DEL /materials/lessons/delete/1/ — Удаление урока с ID = 1

👤 Пользователи (Generics, JWT & CRUD)

  • GET /admin/ — Админ-панель Django (Вход по Email)
  • POST /users/register/ — Регистрация нового пользователя (Доступна анонимам)
  • GET /users/ — Список пользователей (Только публичные данные)
  • PUT /users/profile/2/ — Просмотр профиля Студента из фикстуры (ID=2)
