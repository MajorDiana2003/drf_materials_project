# Django REST Framework — Вьюсеты и Дженерики (ДЗ 30.1)

Проект представляет собой backend-часть для платформы онлайн-обучения. Реализовано управление курсами, уроками и профилями пользователей с использованием **ViewSets** и **Generic API Views** в Django REST Framework.

## 🛠 Технологии и инструменты
* Python 3.x
* Django 5.x / DRF
* Pillow (для работы с превью и аватарками)
* python-dotenv (для управления переменными окружения)
* Flake8 (линтер кода, PEP 8)

---

## 🚀 Инструкция по развертыванию проекта

1. **Клонируйте репозиторий** или распакуйте архив с проектом.
2. **Создайте и активируйте виртуальное окружение**:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate     # Для Windows
   ```
3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Настройте переменные окружения**:
   * Создайте файл `.env` в корневой директории проекта (на основе файла `.env.example`).
   * Добавьте туда ваш `SECRET_KEY` и режим `DEBUG=True`.
5. **Выполните миграции базы данных**:
   ```bash
   python manage.py migrate
   ```
6. **Создайте суперпользователя** (авторизация настроена по Email):
   ```bash
   python manage.py createsuperuser
   ```
7. **Запустите локальный сервер разработки**:
   ```bash
   python manage.py runserver
   ```

## 🗺 Карта эндпоинтов (Маршрутизация)

В проекте настроена удобная **Главная страница-навигатор** (`http://127.0.0`), откуда можно в один клик переходить к тестированию любого эндпоинта.

### 📚 Курсы (Реализовано через ViewSet)
* `GET /materials/courses/` — Получить список всех курсов.
* `POST /materials/courses/` — Создать новый курс.
* `GET /materials/courses/<id>/` — Получить детальную информацию о курсе.
* `PUT/PATCH /materials/courses/<id>/` — Редактировать курс.
* `DELETE /materials/courses/<id>/` — Удалить курс.

### 📝 Уроки (Реализовано через Generic API Views)
* `GET /materials/lessons/` — Список всех уроков.
* `POST /materials/lessons/create/` — Создать новый урок (требуется передать ID существующего курса).
* `GET /materials/lessons/<id>/` — Просмотр одного урока.
* `PUT/PATCH /materials/lessons/update/<id>/` — Редактирование урока.
* `DELETE /materials/lessons/delete/<id>/` — Удаление урока.

### 👤 Пользователи и Безопасность
* `/admin/` — Панель администратора Django. Авторизация переопределена и работает по **Email** вместо `username`.
* `GET/PUT/PATCH /users/profile/<id>/` — Просмотр и редактирование профиля пользователя. 
  * *Безопасность:* Защищено с помощью `IsAuthenticated` и кастомного пермишена `IsOwner`. Просматривать и изменять данные может только авторизованный владелец конкретного профиля. Пароли в базе данных хранятся в хэшированном виде.
