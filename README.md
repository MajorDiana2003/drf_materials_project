 # Django REST Framework — Права доступа и авторизация (ДЗ 31)

Проект представляет собой защищенную backend-часть для платформы онлайн-обучения. Реализовано глобальное разграничение прав доступа для модераторов и владельцев объектов, а также внедрена **JWT-авторизация**.

## 🛠 Добавленные технологии
* `djangorestframework-simplejwt` (авторизация по токенам)
* `django-filter` (фильтрация платежей)

---

## 🚀 Быстрый запуск и авторизация

1. **Установите новые зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
2. **Примените миграции** (добавлены поля владельцев `owner` и обновлен тип даты платежей):
   ```bash
   python manage.py migrate
   ```
3. **Загрузите фикстуру группы модераторов**:
   ```bash
   python manage.py loaddata users/fixtures/groups_data.json
   ```
4. **Запустите локальный сервер**:
   ```bash
   python manage.py runserver
   ```

### 🔑 Работа с JWT-токенами
Для отправки запросов к защищенным эндпоинтам через Postman выполните следующие шаги:
1. Отправьте `POST`-запрос на `/api/token/`, передав в теле (`Body`) ваш `email` и `password`.
2. Скопируйте полученный `access`-токен.
3. Вставляйте его во все последующие запросы в заголовок: `Authorization: Bearer <ваш_токен>`.

## 🗺 Карта эндпоинтов (Маршрутизация)

В проекте работает **Главная страница-навигатор** (`http://127.0.0`), откуда можно переходить к тестированию.

### 🔐 Авторизация и Управление пользователями
* `POST /users/register/` — Регистрация нового пользователя (**доступна анонимам**).
* `POST /api/token/` — Получение пары access/refresh JWT-токенов (**доступно анонимам**).
* `POST /api/token/refresh/` — Обновление access-токена.
* `GET /users/` — Список всех пользователей (выводятся строго публичные данные).
* `GET/PUT/PATCH/DELETE /users/profile/<id>/` — Управление профилем.
  * **Дополнительное задание:** Если авторизованный пользователь запрашивает *свой* профиль, отдается полная информация с историей платежей. Если запрашивается *чужой* профиль — отдается укороченный публичный JSON (без пароля, фамилии и платежей).

### 📚 Курсы и Уроки (Права доступа)
* `GET /materials/courses/` и `GET /materials/lessons/` — Просмотр контента.
* `POST /materials/courses/` и `POST /materials/lessons/create/` — Создание сущностей. При создании поле `owner` автоматически заполняется текущим пользователем.
* Управление конкретными объектами (`retrieve`, `update`, `destroy`).

**Матрица прав доступа (Permissions):**
* **Обычный пользователь:** Может создавать контент. Имеет полный доступ (редактирование/удаление) **только к своим** курсам и урокам.
* **Модератор (группа "модераторы"):** Может просматривать и редактировать **любые** курсы и уроки в системе для контроля качества, но **не имеет права создавать новые или удалять существующие** объекты.
